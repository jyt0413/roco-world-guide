# 🥚 小洛克攻略站 ·《洛克王国：世界》

一个玩家自制的洛克王国手游攻略网站（纯静态，无需安装任何依赖，双击即可打开）。

## ✨ 网站功能

- **📢 官方实时活动公告**：收录官方渠道的最新活动（限时捕捉、版本更新、周年庆典等），
  支持按「进行中 / 即将开启 / 已结束」筛选，进行中的活动带实时倒计时。
- **🥚 查蛋系统**：输入精灵蛋的**尺寸（米）**与**重量（千克）**，自动匹配玩家实测数据表，
  推测蛋中的精灵，并给出**用球建议**（普通球 / 高级球 / 棱镜球 / 炫彩球）。
  内置 5 档重量区间共 90+ 条对照数据，支持展开查阅完整对照表。
- **⚔️ PVP 阵容**：来自社区不同创作者的实战阵容（雷暴双子星、冻结控场、雨天增益、魔法输出、润泽增益等），一键复制阵容文本。
- **🌿 PVE 攻略**：开荒御三家（迪莫 / 燃薪虫 / 罗隐）、翠顶夫人+独角兽、用球策略、新手推进路线。
- **🐣 孵蛋知识**：生蛋三要素、子代规则、孵化机制、查蛋用球技巧。
- **✨ 动态视觉**：魔法粒子星空、浮岛视差、打字机标题、滚动渐显、孵蛋动画、卡片悬浮动效。

## 🔄 如何更新公告内容

所有数据集中在 `js/data.js` 的 `SITE_DATA` 对象中：

| 字段 | 说明 |
| --- | --- |
| `updatedAt` | 数据收录时间（显示在公告区） |
| `announcements` | 公告数组：`title` 标题、`tag` 标签、`start/end` 起止时间（ISO 格式，用于自动判断状态与倒计时）、`details` 要点、`source/url` 来源 |
| `eggZones` | 查蛋对照表：5 档重量区间，每只精灵含 `name / l0-l1（蛋长）/ w0-w1（重量）` |
| `pvp` / `pve` | 阵容与攻略卡片 |

修改后保存，刷新浏览器即可生效。公告状态（进行中/即将/已结束）与倒计时由 JS 根据当前时间自动计算。

## 🤖 自动更新机制（GitHub Actions）

仓库内置定时任务 `.github/workflows/auto-update.yml`，**每 6 小时自动运行一次**（也可在仓库 Actions 页面手动触发）：

1. 抓取数据源：
   - 17173「洛克王国」资讯标签页（GBK 解码，含手游/页游资讯）
   - 洛克王国官网新闻公告列表 `roco.qq.com`（官方页游公告）
   - 9game「洛克王国手游」攻略频道（PVP/PVE 攻略速递）
2. 自动合并去重到 `content/auto.json`（公告最多 40 条、攻略速递最多 60 条）
3. 生成 `js/auto.js` 并提交推送，GitHub Pages 自动重新发布

- 自动公告在网站上显示为「📰 资讯」徽章，按发布日期排序；攻略速递显示在 PVP / PVE 板块下方。
- 数据源抓取失败时保留旧数据，不影响线上网站。
- 手动运行一次：仓库 → Actions → "自动更新公告与攻略速递" → Run workflow。
